*   **LCRS Array Optimization**: We made a brilliant discovery! The structural indices (`parent`, `child`, `sibling`) are ALREADY using `uint8_t` by default. Furthermore, when compiling for ARM Cortex-M, the `arm-zephyr-eabi-gcc` compiler automatically uses `-fshort-enums`, packing the `enum btf_node_status` into exactly 1 byte. This means that `struct btf_node` ALREADY natively achieves the theoretical limit of 8 bytes on 32-bit MCUs without any code changes.
